# Policy Management System

## Overview

This project implements a simple Policy Management System for an insurance company. It manages:

- **Policyholders**: Registering, suspending, and reactivating policyholders.
- **Products**: Creating, updating, and suspending insurance products.
- **Payments**: Processing payments, managing reminders, and penalties.

The system is organized into separate classes representing Policyholders, Products, and Payments.

---

## Files

- `Policyholders_Class.ipynb`  
  Contains the `Policyholder` class definition and related methods.

- `Product_Management.ipynb`  
  Contains the `Product` class and product management methods.

- `Payment_Class.ipynb`  
  Contains the `Payment` class with payment processing, reminders, and penalties.

- `Policy Holder Demonstration.ipynb`  
  Demonstrates usage by creating policyholders, products, and processing payments.

---

## How to Run

1. Open the `Policy Holder Demonstration.ipynb` notebook in Jupyter Notebook or JupyterLab.

2. Ensure all class definitions (`Policyholder`, `Product`, `Payment`) are included in this notebook or imported correctly if using `.py` files.

3. Run all cells in the notebook to see the demonstration of:

   - Creating two policyholders.
   - Creating a product.
   - Processing payments.
   - Displaying policyholder details including payment status.

---

## Notes

- If using separate notebooks for classes, either copy the class code into the demonstration notebook or convert each notebook to `.py` and import them accordingly.

- This project uses Python’s built-in `datetime` module for managing payment due dates.

- Output is printed using Python's `pprint` module for clear, readable display of policyholder details.
