# Police-Management-System
A Python system to manage insurance policyholders, products, and payments using object-oriented programming.

# Insurance Policy Management System

## Overview

This project is an insurance policy management system built using Python and object-oriented programming principles. It is organized into five Jupyter Notebooks, each handling a key component of the system: policyholders, products, payments, management, and demonstration.

## Files and Descriptions

- **Policyholders Class.ipynb**  
  Defines the `Policyholder` class, including attributes and methods for managing individual policyholder accounts (e.g., activate, add payments).

- **PolicyHolderManager.ipynb**  
  Contains the `PolicyholderManager` class, which handles registration, suspension, and reactivation of policyholders using their ID.

- **Product Management.ipynb**  
  Defines the `Product` class and includes methods to create, update, and suspend/remove insurance products.

- **Payment Management.ipynb**  
  Contains the `Payment` class, with methods for processing payments, sending payment reminders, and handling late payment penalties.

- **Policy Holder Demonstration.ipynb**  
  Demonstrates how the system works by:
  - Creating sample products
  - Registering policyholders
  - Processing payments
  - Displaying policyholder account details

## How to Use

1. Open each notebook in **Jupyter Notebook** or **JupyterLab**.
2. Run the class definition notebooks first:
   - `Policyholders Class.ipynb`
   - `PolicyHolderManager.ipynb`
   - `Product Management.ipynb`
   - `Payment Management.ipynb`
3. Then, open and run `Policy Holder Demonstration.ipynb` to test the system in action.
4. Make sure all files are in the same directory so imports work correctly (or copy code directly into the demo file).

## Requirements

- Python 3.x
- Jupyter Notebook or JupyterLab
- No external libraries required
